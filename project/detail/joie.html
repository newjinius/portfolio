영국 글로벌 프리미엄 유아용품 브랜드 Joie(조이)의 한국 공식 쇼핑몰 프론트엔드 개편을 담당했습니다.
Joie Signature 컬렉션·연령별 제품 가이드 등 브랜드 프리미엄 경험을 Swiper 슬라이드와 배너매니저 CMS, 미디어 게시판 팝업 커스터마이징으로 구현했습니다.

— Key Features

주요 구현 기능 슬라이드 · 영상 · Signature 라인업

Swiper

Feature 01

다양한 레이아웃의
Swiper 슬라이드 구현

홈페이지 내 메인 히어로부터 Joie Signature 컬렉션, 연령별 제품 추천, 베스트셀러까지 섹션별로 차별화된 Swiper 레이아웃을 구현했습니다. 각 섹션의 콘텐츠 성격에 맞는 슬라이드 레이아웃으로 프리미엄 브랜드 경험을 강화했습니다.

  • 메인 히어로·Signature·연령별·베스트 섹션별 Swiper 레이아웃 개별 설계
  • 루프·자동재생·페이드·슬라이드 전환 효과 섹션별 커스터마이징
  • breakpoints 설정으로 PC·태블릿·모바일 최적 슬라이드 수·간격 자동 대응
배너매니저

Feature 02

배너매니저 기반
헤더 카테고리 & Signature 라인업

Cafe24 배너매니저 앱을 활용해 헤더 카테고리 이미지·링크와 Joie Signature 라인업 페이지 콘텐츠를 운영팀이 직접 관리할 수 있도록 구조를 설계했습니다. 신제품 출시·시즌 이벤트 시 개발 요청 없이 즉시 대응 가능합니다.

  • GNB 헤더 카테고리 이미지·링크를 배너매니저로 관리하는 구조 구현
  • Joie Signature·카시트·유모차 라인업 페이지 핵심 영역 CMS화
  • 카시트 선택 가이드 페이지 콘텐츠 배너매니저 기반 운영 구조 적용
YouTube

Feature 03

유튜브 영상 기반
미디어 슬라이드 구현

Joie 유튜브 채널의 제품 안전 테스트·사용 가이드·리뷰 영상을 슬라이드 형태로 홈페이지에 노출했습니다. 썸네일 선택 시 슬라이드가 해당 영상으로 전환되어 인라인 재생되므로 브랜드 신뢰도 강화 콘텐츠를 페이지 이탈 없이 소비할 수 있습니다.

  • YouTube IFrame API + Swiper 조합 미디어 슬라이드 구현
  • 썸네일 선택 시 활성 슬라이드 전환 + 유튜브 영상 인라인 재생
  • 자동 썸네일·제목 로드로 채널 업로드 시 별도 작업 없이 반영
팝업 커스텀

Feature 04

Cafe24 미디어 게시판
팝업 형태 커스터마이징

Cafe24 기본 게시판을 Joie 미디어(영상·보도자료) 전용 게시판으로 재활용했습니다. 목록에서 게시글 클릭 시 새 페이지 이동 없이 레이어 팝업으로 유튜브 영상과 콘텐츠가 노출되도록 전면 커스터마이징했습니다.

  • Cafe24 기본 게시판을 미디어 팝업 전용 구조로 재정의 및 UI 전면 커스텀
  • 게시글 클릭 시 레이어 팝업 형태로 유튜브 영상 + 정보 노출
  • 게시판 데이터(제목·날짜·내용·카테고리)를 팝업 레이아웃에 맞게 재배치
  • ESC 키·배경 클릭 닫기·이전/다음 게시글 탐색 UX 추가 구현

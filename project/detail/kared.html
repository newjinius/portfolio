Feature 01

디자인 스킨 리뉴얼 &
업셀링 외부 앱 연동

민감성 피부 전문 브랜드 케어드의 정체성에 맞게 Cafe24 디자인 스킨을 클리니컬 미니멀 감성으로 리뉴얼했습니다. 동시에 업셀링 외부 앱을 스킨에 자연스럽게 녹여내어 구매 전환율을 높이는 상품 추천 UI를 구현했습니다.

  • 브랜드 아이덴티티(클리니컬·미니멀)에 맞는 색상·타이포·레이아웃 전면 재정의
  • 업셀링 외부 앱 스킨 내 통합 — 상품 상세·장바구니 영역 추천 UI 노출
  • 앱 UI가 스킨 디자인과 이질감 없이 어우러지도록 스타일 오버라이드 처리
  • 약국 입점 안내·성분 강조 섹션 등 브랜드 특화 콘텐츠 영역 신규 구성
UX Fix

Feature 02

이미지 로드 지연으로 인한
앵커 이동 오류 개선

상품 상세 페이지에서 "상세정보 / 리뷰 / 배송안내" 탭 클릭 시 스크롤이 잘못된 위치로 이동하는 버그를 해결했습니다. 고해상도 상세 이미지가 로드되기 전에 앵커 이동이 실행되어 레이아웃 높이가 확정되지 않은 것이 원인이었습니다.

  • 이미지 미로드 상태에서 앵커 이동 → 이미지 로드 후 높이 확정 → 스크롤 위치 어긋나는 원인 분석
  • 이미지에 고정 aspect-ratio 부여 → 로드 전부터 레이아웃 공간 확보로 레이아웃 시프트 차단
  • 앵커 클릭 이벤트에 requestAnimationFrame 래핑 → 렌더링 완료 후 스크롤 실행 보장
  • Cafe24 기본 앵커 이벤트와 충돌 없이 동작하도록 이벤트 위임 구조로 처리
핵심 원인: 이미지 높이가 확정되지 않은 시점에 스크롤 위치를 계산하므로 앵커 좌표가 틀어짐. aspect-ratio로 레이아웃 공간을 미리 확보하면 이미지 로드 전후 높이가 동일하게 유지되어 CLS(Cumulative Layout Shift)와 앵커 오류를 동시에 해결.

Responsive Design

모바일에서도
끊김 없는 탐색 경험

스킨케어 제품은 모바일 탐색 비중이 높습니다. 리뉴얼 스킨 전체와 앵커 버그 수정 모두 모바일 환경에서 검증했으며, 특히 긴 상세 이미지가 많은 스킨케어 특성상 모바일 앵커 오류 수정이 더욱 중요했습니다.

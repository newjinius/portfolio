Core

Feature 01

인쇄 유형별
주문제작 상세 페이지

인쇄 유형 4종(동판·인디고·디지털·스티커)마다 옵션 구조가 달라, 유형별 주문 폼을 따로 구현했습니다. 디지털 인쇄는 형태 → 제품 → 사이즈를 단계적으로 고르는 선택형 UI로 제작했습니다.

  • 유형별 옵션 폼 분리 : 원단 1·2차, 후가공, 용지·코팅·모양·사이즈
  • 디지털 인쇄 : 카테고리 클릭 시에만 Cafe24 Front API 호출, 페이지네이션
  • 옵션 간 연동 — "인쇄없음" 선택 시 디자인 유무 "없음"으로 자동 세팅
  • 무료배송 게이지 : 총 결제금액 감지해 10만원 기준 잔여 금액 표시
Upload

Feature 02

디자인 파일 첨부
S3 연동

Cafe24 기본 기능으로는 고객 파일을 받을 수 없어, 외부 스토리지 업로드와 주문 옵션을 직접 연결했습니다. 회원 토큰을 담은 미들웨어 API로 S3에 업로드하고, 반환된 URL이 추가입력옵션에 자동으로 들어갑니다.

  • 파일 검사 : 이미지·pdf·ai·psd, 최대 2개, 건당 30MB, 썸네일 미리보기·삭제
  • 미들웨어 업로드 API → S3 저장 → 파일 URL 반환 → 추가입력옵션 자동 입력
  • 디자인 유무에 따라 파일첨부 영역 노출·필수 조건 전환
  • 화면에서 숨긴 옵션도 주문에 전송되도록 화면 밖 배치 처리
API

Feature 03

견적문의 게시판
API 연동

미들웨어 API로 견적문의 목록·작성·조회 화면을 구현했습니다. 회원/비회원 인증을 분리하고, 재발행 상태일 때만 컨펌 버튼을 활성화하는 등 견적 흐름에 맞는 상태 관리를 추가했습니다.

  • 조회 인증 : 회원은 토큰, 비회원은 비밀번호
  • 작성자명 마스킹, 견적 상태값 한글 매핑, 연락처 하이픈 자동 입력
  • 재발행 상태일 때만 견적 컨펌 버튼 활성화
  • 이메일 필드를 입력 → 전송 → 조회까지 전 구간 API 연동

Responsive Design

복잡한 주문제작,
모바일에서도 완결

포장재 B2B 주문은 모바일에서도 인쇄 유형 선택, 파일첨부, 옵션 확인이 모두 필요합니다. 화면에서 숨긴 input이 주문에 전송되도록 화면 밖 배치 방식을 적용해, 복잡한 옵션 흐름을 모바일에서도 끊김 없이 동작하게 했습니다.

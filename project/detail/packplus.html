포장재 전문 쇼핑몰 팩플러스(PackPlus)의 Cafe24 스킨 전면 리뉴얼을 담당했습니다.
국문몰 전 페이지 PC·모바일 반응형 리뉴얼, Cafe24에 없는 S3 디자인 파일첨부 기능 구현, 인쇄 유형별 주문 폼 및 견적게시판 API 연동, 그리고 영문몰 이관 336개 파일 자동 분류까지 진행했습니다.

Feature 01

국문몰 전 페이지
PC·모바일 반응형 리뉴얼

포장재 전문 쇼핑몰 팩플러스의 전 페이지를 새 디자인 시안에 맞게 리뉴얼했습니다. 메인·리스트·상세·주문서·마이페이지 등 모든 페이지를 PC와 모바일 반응형으로 구현했으며, Claude Code로 구현하고 Figma 시안과 픽셀 단위로 대조해 완성했습니다.

  • 전 페이지 Cafe24 partial(37개) 시안 기반 재구성
  • 헤더·푸터·LNB·메가메뉴 공통 레이아웃 전면 재정의
  • 상품 리스트·상세·옵션 UI 브랜드 아이덴티티에 맞게 재구성
  • Playwright 실측으로 Figma 시안 수치와 픽셀 단위 대조
Feature

Feature 02

S3 디자인 파일첨부 &
인쇄 유형별 주문 폼

Cafe24에 기본 제공되지 않는 디자인 파일 첨부 기능을 직접 구현했습니다. 고객이 상세 페이지에서 인쇄 디자인 파일을 업로드하면 AWS S3에 저장되고, URL이 주문 옵션에 자동 연결됩니다. 인쇄 유형 4종(디지털인쇄·동판인쇄·스티커·맞춤제작)에 맞는 주문 폼과 견적문의 게시판 API도 함께 연동했습니다.

  • AWS S3 업로드 → URL 자동 주문 옵션 연결
  • 인쇄 유형별 분기 폼 (4종) · 파일첨부 필수/선택 조건 검증
  • 견적문의 게시판 커스텀 API 연동 (이메일·파일첨부·페이지네이션)
  • 카페24 :visible 필터 함정 선제 차단 — 숨긴 input 값 off-screen 배치
Migration

Feature 03

영문몰 이관 336파일
자동 분류 & 체크리스트

국문몰 완성 후 영문몰 이관 작업을 진행했습니다. 국문/영문 차이가 나는 파일 336개를 Node.js 스크립트로 자동 분류해 이관 범위를 빠르게 파악했습니다. 이관 후 고객사가 직접 운영할 수 있도록 체크리스트와 운영 가이드도 제작했습니다.

  • 국문·영문몰 파일 diff 자동 분류 스크립트 (336개 파일 처리)
  • 한글 텍스트 잔존 여부 자동 검출, 대분류·중분류 카테고리명 번역
  • 영문몰 전용 설정(세금계산서·부가세 표기) 별도 처리
  • 고객사 운영 체크리스트 제작 — 배포 후 즉시 확인 항목 정리

Responsive Design

모바일에서도
완결된 주문 경험

포장재 B2B 주문은 모바일에서도 복잡한 옵션을 다뤄야 합니다. 인쇄 유형 선택, 파일첨부, 견적 요청까지 모바일에서도 끊기지 않도록 반응형을 설계했습니다. 카페24의 `:visible` 필터 함정도 모바일 주문 흐름에서 선제 차단했습니다.

★
모바일 주문 폼 완결성 인쇄 유형별 분기 폼이 모바일에서도 정확하게 작동, 숨긴 input 값 손실 없음
★
파일첨부 UX 모바일에서 디자인 파일 첨부·S3 업로드 흐름 전 기기 검증
★
반응형 전 페이지 메인부터 마이페이지까지 전 페이지 모바일 최적 레이아웃·타이포·여백 조정

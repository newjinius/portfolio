국내 대표 캠핑·아웃도어 장비 브랜드 코베아(KOVEA)의 Cafe24 커머스 커스터마이징을 담당했습니다.
Cafe24 프론트 API를 활용한 카테고리 상품 노출 커스터마이징과, 화면경로 설정을 통해 상품 모듈을 상품 목록 페이지 외 영역에서도 활용하여 기획전 형식 페이지를 구현했습니다.

API

Feature 01

카페24 프론트 API 기반
상품 카테고리 커스터마이징

Cafe24 프론트 API를 직접 호출하여 카테고리 내 상품 데이터를 가져오고, 기본 상품 목록 레이아웃으로는 구현할 수 없는 커스텀 노출 방식을 구현했습니다. 브랜드별·시즌별로 다른 상품 배치와 UI를 API 응답 데이터 기반으로 동적으로 렌더링했습니다.

  • Cafe24 상품 카테고리 API 엔드포인트 분석 및 프론트 직접 호출 구현
  • API 응답 데이터 기반 커스텀 상품 카드 UI 동적 렌더링
  • 카테고리별 정렬·필터 옵션을 API 파라미터로 연동하여 상품 노출 제어
  • 기본 Cafe24 상품 목록 모듈의 한계를 우회한 자유도 높은 레이아웃 구현
활용 포인트: Cafe24 기본 모듈은 레이아웃 변경에 제약이 많음. 프론트 API를 직접 호출하면 응답 데이터를 원하는 HTML 구조로 자유롭게 렌더링 가능 — 브랜드 아이덴티티에 맞는 완전 커스텀 카테고리 페이지 구현.
기획전

Feature 02

화면경로 설정으로
상품 모듈 활용 기획전 구현

Cafe24의 화면경로(화면 ID) 설정을 활용하여 일반 상품 목록 페이지가 아닌 별도 레이아웃에서도 상품 모듈을 불러올 수 있도록 구성했습니다. 이를 통해 다양한 섹션 구성이 가능한 기획전 형식 페이지를 구현했습니다.

  • Cafe24 화면경로(화면 ID) 설정을 활용한 상품 모듈 호출 범위 확장
  • 기획전 전용 레이아웃 페이지에 상품 모듈을 자유 배치하여 기획전 형식 구현
  • 콘텐츠 배너·텍스트 영역과 상품 모듈을 혼합 배치하는 커스텀 기획전 구조 설계
  • 운영팀이 기획전 상품을 카테고리 연결만으로 손쉽게 교체할 수 있는 구조 유지
핵심 기법: Cafe24 상품 모듈은 기본적으로 지정된 화면(상품 목록 등)에서만 동작. 화면경로 ID 설정을 통해 임의 페이지에서도 모듈이 동작하도록 확장 — 별도 API 없이 Cafe24 모듈 시스템 내에서 기획전 페이지 구현 가능.

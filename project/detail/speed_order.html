— Key Features

주요 구현 기능 단계별 선택 · 분기 · 데이터 관리

Branching

Feature 01

선택지 기반
결과 페이지 분기

사용자가 선택한 항목에 따라 다음 단계와 최종 결과 페이지가 달라지도록 분기 처리를 구현했습니다. 어떤 조합을 선택해도 정확한 결과로 안내하는 흐름을 설계했습니다.

  • 단계별 선택지 UI 구성 및 조건 분기 로직 구현
  • 선택 값에 따른 다음 단계 / 결과 페이지 동적 매핑
  • 이전 선택 상태 유지 및 되돌아가기 처리
Swiper

Feature 02

Swiper 기반
부드러운 전환 인터랙션

항목 선택 시 단순 페이지 이동이 아닌, Swiper를 활용해 슬라이드처럼 부드럽게 다음 단계로 전환되는 효과를 구현했습니다. 사용자에게 흐름의 연속성을 자연스럽게 전달합니다.

  • Swiper 슬라이드 전환으로 단계 이동 시 부드러운 스크롤 효과
  • 선택 즉시 다음 단계로 전환되는 즉각적 피드백 UX
  • 전환 방향·속도 커스터마이징으로 브랜드 분위기 반영
Data

Feature 03

경우의 수를 고려한
프론트 데이터 구조

선택 항목과 결과 매핑을 HTML에 하드코딩하지 않고, 별도 JS 파일로 분리해 데이터를 관리했습니다. 새로운 선택지·결과 추가 시 코드 최소 수정으로 확장 가능한 구조를 설계했습니다.

  • 선택지·결과 데이터를 별도 JS 파일에서 중앙 관리
  • 경우의 수 조합 전체를 커버하는 매핑 자료 구조 설계
  • 운영팀이 JS 데이터만 수정해 콘텐츠 확장 가능한 구조

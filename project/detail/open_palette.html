아티스트와 컬렉터를 잇는 대규모 아트 커머스 플랫폼 구축 프로젝트입니다.
해시태그·컬러칩·슬라이더 기반 고도화 필터, 아티스트·큐레이터·마스터 3단계 권한 분기, WebGL 팀과의 협업을 통한 3D 전시 연동까지, 복잡한 아트 커머스 기능을 종합적으로 구현했습니다.

— Key Features

담당 기능 구현한 주요 기능들

Core

Feature 01

아트 커머스
큐레이션 기능 구현

Cafe24 쇼핑 큐레이션을 커스터마이징하여 작품 탐색에 최적화된 다차원 필터 UI를 구현했습니다. 해시태그·컬러·사이즈·가격까지 복합 조건으로 원하는 작품을 정밀하게 탐색할 수 있습니다.

  • Cafe24 쇼핑 큐레이션 기능 스크립트 기반 커스터마이징
  • 해시태그 기반 다중 필터 기능 구현
  • 사이즈 / 가격 범위 슬라이더 UI 구현
  • 컬러칩 기반 필터 인터랙션 구현
Auth

Feature 02

회원 유형별
기능 및 권한 분기 처리

API 연동을 통해 회원 상태를 실시간으로 파악하고, 아티스트·큐레이터·마스터 3단계 권한에 따라 접근 가능한 기능과 노출 콘텐츠를 정밀하게 분기 처리했습니다.

  • API 연동을 통한 회원 상태별 기능 제어
  • 아티스트 / 큐레이터 / 마스터 3단계 권한 분기
  • 권한별 화면 구성·콘텐츠·기능 노출 제어
  • 비로그인 / 권한 미달 상태별 안내 처리
WebGL

Feature 03

WebGL 기반
작품 3D 전시 연동

WebGL 개발팀과 협업하여 작품 3D 전시 콘텐츠를 프론트 화면에 연동하고, 인터페이스 UI를 구현했습니다. 갤러리 감성의 몰입형 작품 감상 경험을 제공합니다.

  • WebGL 개발팀 협업을 통한 3D 전시 화면 연동
  • 프론트 화면과 WebGL 콘텐츠 간 인터페이스 구현
  • 작품별 조건에 따른 3D 전시 노출 분기 처리
Responsive

Feature 04

PC / 모바일
반응형 UI 구현

PC와 모바일 환경의 사용자 경험 차이를 고려하여 디바이스별 최적의 레이아웃과 인터랙션을 설계했습니다. 작품 감상 및 구매 플로우 모두 전 환경에서 완성도 있게 동작합니다.

  • PC / 모바일 동시 대응 반응형 웹 구현
  • 디바이스별 레이아웃 및 컴포넌트 최적화
  • 터치 인터랙션 및 모바일 UX 개선
  • 화면별 UI 분기 및 인터랙션 차별화 적용
Team

Feature 05

프론트 코드 컨벤션
정립

대규모 아트 커머스 플랫폼 구축 과정에서 팀 전체의 코드 일관성을 확보하기 위한 프론트 코드 작성 규칙을 수립하고, 팀 내 공통 가이드로 활용했습니다.

  • HTML / CSS / JavaScript 코드 작성 규칙 수립
  • 공통 컴포넌트 및 변수 네이밍 가이드 정리
  • 팀 내 프론트 개발 컨벤션 기준으로 활용
  • 유지보수성 및 협업 효율 향상에 기여

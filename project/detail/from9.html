초대 코드를 받은 평가자만 입장하는 FROM9 품질평가 캠페인몰입니다.
코드 종류와 평가 여부에 따라 메인이 5가지로 분기되는 구조를 설계했습니다. 평가 API, 월 구매 한도 검증, 초대·쿠폰 기능을 연동하고, 상세 2차 리뉴얼과 공식몰 이식까지 진행했습니다.

Core

Feature 01

사용자 상태별
5개 시나리오 메인

평가 코드 종류(일반·디마르)와 평가 여부에 따라 메인 화면을 5가지(s0–s4)로 분기했습니다. 공통 메인 하나에 partial import와 상태 클래스를 조합해 노출을 제어하고, 권한 판정 전에는 화면을 보이지 않게 해 로그인 직후 깜빡임을 제거했습니다.

  • s0 메인 진입 / s1·s2 일반코드 평가 전·후 / s3·s4 디마르코드 평가 전·후
  • 공통 메인 + partial import + 상태 클래스로 노출 분기
  • 권한 판정 전 화면 opacity 0 → 응답 후 fade-in, 깜빡임 제거
  • 시나리오별 노출 매트릭스로 영역별 표시 조건 관리
API

Feature 02

품질평가 시스템 &
월 구매 한도

평가 참여에 필요한 화면 전체를 API와 연동했습니다. 실시간 평가금액 그래프, 리뷰·댓글 작성, BEST 댓글 슬라이드를 구현했습니다. 평가자 혜택가 구매는 제품당 월 7개 한도를 주문서 단계에서 검증하고, 한도를 넘으면 결제 진행 자체를 차단했습니다.

  • 총 평가자 수·상품별 실시간 평가금액 API, 가격 그래프 슬라이드
  • 평가 작성·삭제, 리뷰·댓글·대댓글, BEST 댓글 슬라이드 (조작 중 자동전환 정지)
  • 첫 평가 완료 팝업 : 권한 부여 시점에만 노출, 남은 혜택 기간 표시
  • 구매 한도 초과 시 알럿이 아닌 결제 진행 차단, 한도 대상 상품만 판정
Detail

Feature 03

상품 상세 2차 리뉴얼
& 운영 도구

상세 페이지를 데이터와 렌더러를 분리한 구조로 바꾸고, 고객사가 직접 수정할 수 있는 JSON 편집기를 제작했습니다. 인체적용시험 탭, 전후 비교 슬라이더, 효능 별점을 추가했으며, 공식몰 이식 시 프로모션 전용 요소를 제외하는 기준도 정리했습니다.

  • 원료 데이터와 렌더러 분리, 3단계 케어 라인업, 전후 비교 슬라이더
  • 브라우저에서 바로 쓰는 상세 JSON 편집기 (엑셀 변환기 대체)
  • Vimeo HLS(m3u8) 재생, poster·placeholder 분리 구조
  • 공식몰 이식 시 프로모션 전용 요소 제외 기준 문서화

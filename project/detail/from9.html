Feature

Feature 01

사용자 상태별
5개 시나리오 분기 메인

평가자의 권한·참여 상태에 따라 단일 메인 페이지에서 s0(비회원)·s1(참여 전)·s2(참여 중)·s3(평가 완료)·s4(혜택 적용) 5개 시나리오가 자동 분기됩니다. API 응답 전까지 로딩 상태를 처리해 화면 깜빡임을 제거했고, 각 시나리오별 노출 영역이 다른 계정에 보이지 않도록 분기 매트릭스를 정밀하게 관리했습니다.

  • 권한 API 응답 기반 s0–s4 자동 분기, 오노출 방지
  • API 응답 전 로딩 상태 처리 — opacity fade-in으로 깜빡임 제거
  • 시나리오별 노출 매트릭스 문서화, 회원명·평가 버튼·참여완료 배너 분기
  • 프리뷰 환경 shop·skin 경로 SkinPath.to() 공통 유틸 일원화
Design

Feature 02

750px Figma 시안
480px 1:1 구현

750px 기준 Figma 시안을 480px 모바일 스킨에 1:1로 옮겼습니다. Playwright의 getBoundingClientRect로 여백·크기를 실측해 시안과 대조했습니다. 영상 영역·텍스트 노드·투명 자산을 이미지 처리하지 않도록 지속 감시했고, 피그마 프레임 밖 주석(영상/이미지 구분, 스크롤 지시)까지 확인하도록 검수 프로세스를 수립했습니다.

  • Figma MCP 연결 → 섹션 단위 구현 지시 → Playwright 픽셀 실측 반복
  • 영상 영역을 정지 이미지로 처리한 3곳 지적·영상으로 교정
  • 텍스트 노드를 이미지 크롭에 담지 않도록 HTML 재구성
  • 여백 198px 누락 등 "모든 영역 반영" 보고 후에도 차이 발견·재작업
API & Tool

Feature 03

평가 API · 구매한도 가드 &
JSON 편집기

평가자 수·평가금액 집계 API 연동, 월 구매한도를 실제 결제 단계에서 차단하는 가드를 구현했습니다. 고객사가 시나리오별 상세 데이터를 직접 관리할 수 있도록 웹 기반 JSON 편집기도 제작했습니다. sharp WebP 변환으로 이미지 로딩을 최적화하고, 파일명 버전 규칙으로 배포 캐시 문제를 해결했습니다.

  • 평가자 수·금액 API 연동, 첫 평가 완료·이후 평가 팝업 분기
  • 구매한도 가드 — 알럿에서 그치지 않고 실제 결제 진행 차단
  • 웹 기반 상세 JSON 편집기 신규 제작 (고객사 직접 운영)
  • sharp WebP 변환 · 파일명 버전 suffix(v2/v3)로 CDN 캐시 관리

캠페인 스킨

FROM9 프로모션몰은 처음부터 모바일 전용으로 설계된 캠페인 스킨입니다. 750px Figma 시안을 480px 기준으로 1:1 구현했으며, 5개 시나리오가 모두 모바일에서 끊김 없이 분기됩니다. 권한 확인 전 화면이 깜빡이지 않도록 로딩 상태 설계도 모바일 기준으로 검증했습니다.

★

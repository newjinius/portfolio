첫 번째 실무 프로젝트

건강식품 브랜드 대장사랑 Cafe24 쇼핑몰 퍼블리싱을 담당한 첫 번째 실무 프로젝트입니다.
사전 교육 없이 바로 실무에 투입되어, Cafe24 모듈 구조를 직접 분석하고 스킨 퍼블리싱을 완수했습니다. 프로젝트를 통해 체계화한 학습 내용은 이후 사내 신규 입사자 교육 자료로 활용되었습니다.

Feature 01 — 분석 · 퍼블리싱

Cafe24 모듈 구조
직접 분석 및 스킨 퍼블리싱

별도 교육 없이 Cafe24 플랫폼에 투입되어, 공식 문서 및 실제 스킨 코드 분석을 통해 모듈 렌더링 구조·변수 시스템·레이아웃 상속 체계를 스스로 파악했습니다. 파악한 구조를 기반으로 대장사랑 쇼핑몰 스킨 퍼블리싱을 완수했습니다.

  • Cafe24 모듈 렌더링 구조 — 레이아웃 상속, 변수 선언, 조건부 출력 방식 파악
  • 스킨 파일 구조(layout/module/page) 분석 및 커스텀 스킨 퍼블리싱 적용
  • JavaScript를 활용한 UI 인터랙션 구현 (메뉴, 배너, 상품 목록 등)
  • HTML/CSS 마크업 설계 — 시맨틱 구조 및 반응형 레이아웃 구현
실무 투입 배경: 사전 Cafe24 교육 없이 첫날부터 실제 프로젝트에 배정. 공식 문서 + 기존 스킨 역분석 + 실험을 반복하며 플랫폼 구조를 스스로 체계화했고, 이후 해당 지식이 팀 내 표준 이해의 기반이 됨.

Feature 02 — 문서화 · 사내 자산

Cafe24 구조 정리 PPT
→ 신규 입사자 교육 자료로 활용

프로젝트를 진행하며 스스로 파악한 Cafe24 구조와 개발 흐름을 체계적으로 정리하여 PPT를 제작했습니다. 해당 자료는 추후 신규 입사자가 Cafe24를 처음 접할 때 참고할 수 있는 팀 내 교육 자료로 채택되어 활용되었습니다.

  • Cafe24 플랫폼 구조 전반 — 파일 구성, 모듈 체계, 변수·조건문 문법 정리
  • 실무 워크플로우 — 스킨 신규 등록, 파일 업로드, 미리보기 환경 구성 과정 문서화
  • 실수하기 쉬운 포인트 및 트러블슈팅 사례 포함 — 실전 경험 기반 정리
  • 신규 입사자 온보딩 자료로 채택 → 팀 내 공유 자산으로 지속 활용

— Key Features

담당 기능 구현한 주요 기능들

Core

Feature 01

예약 연계
주문 프로세스 구현

Cafe24 기본 주문 기능에 매장 선택 및 예약 일정 선택 기능을 연동하여 장착 예약형 구매 프로세스를 구현했습니다.

  • 상품 선택 → 매장 선택 → 예약 일정 조회 → 시간 선택 → 주문 플로우
  • 어드민·파트너스 앱과 연동되어 매장별 예약 관리 가능한 화면 구현
  • 미들웨어 API 연동을 통한 주문·예약 데이터 처리
  • 내 차량 등록 / 차량 점검 예약 / 챌린지 미션 / 알림 기능 연동
UX

Feature 02

원스텝 구매 UX
끊김 없는 구매 흐름

상품 선택부터 매장 선택, 장착 옵션, 예약 일정, 수량 선택, 주문서 이동까지 하나의 영역 내에서 처리할 수 있는 통합 구매 UX를 구현했습니다.

  • Cafe24 주문 모듈(iframe) 연동으로 상세 페이지 내 끊김 없는 구매 흐름
  • 모바일 환경 단계별 UI 노출 제어로 예약 프로세스 UX 개선
  • 단계 전환 시 자동 스크롤 적용

Feature 03

차량 기반
상품 검색 기능

카젠 API를 연동하여 보유 차량 정보를 기반으로 맞는 타이어를 찾을 수 있는 '내 차로 찾기' 기능을 구현했습니다.

  • 카젠 API 연동 '내 차로 찾기' 기능
  • 차량 등록 및 차량 점검 예약 기능 연동
  • 차종/브랜드 기반 검색 및 타이어 사이즈 검색
Maps

Feature 04

Google Maps 연동
매장 찾기 서비스

Google Maps API를 연동하여 사용자 위치 기반으로 가까운 타이어프로 매장을 탐색할 수 있는 매장 찾기 기능을 구현했습니다.

  • 지역 검색 / 자동완성 / 매장명 검색
  • 사용자 위치 기반 거리순 매장 노출
  • 지도 마커 클릭 시 매장 상세 정보 표시
WebGL

Feature 05

WebGL 기반
3D 매장 콘텐츠 연동

WebGL 개발팀과 협업하여 매장 상세 페이지 내 3D 매장 콘텐츠를 연동하고, 매장별 조건에 따라 콘텐츠 노출을 분기 처리했습니다.

  • iframe 기반 WebGL 영역 연동 및 매장 상세 화면 노출
  • 매장별 템플릿 조건에 따른 3D 콘텐츠 노출 분기 처리
  • 매장별 안내 메시지 및 노출 문구 적용
  • 프론트 화면과 WebGL 콘텐츠 간 UI 연동

Feature 06

제휴몰·외부 서비스
연동 기능

제휴몰 유입 시 쿠키 기반으로 제휴사별 할인 권한을 자동 적용하고, 임직원몰의 경우 별도 인증 코드를 통한 권한 부여 프로세스를 구현했습니다.

  • 쿠키 기반 제휴사별 할인 권한 자동 적용
  • 제휴몰별 혜택 및 구매 프로세스 분기 처리
  • 임직원몰 인증 코드 입력을 통한 권한 부여
  • 게시판 / 리뷰 / 프로모션 키트 및 사내 솔루션 연동
  • 상세 페이지 플로팅 영상 외부 서비스 앱 설치·적용

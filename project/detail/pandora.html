— Key Features

담당 기능 구현한 주요 기능들

Banner

Feature 01

메인 배너
템플릿화

배너매니저와 스크립트를 결합하여 각 슬라이드 항목마다 다양한 레이아웃과 스타일을 독립적으로 구성할 수 있는 배너 템플릿 시스템을 구축했습니다.

  • 배너 크기 3단(대·중·소) 옵션 및 띠배너 동시 사용
  • 항목별 텍스트 컬러·버튼 컬러 개별 지정 가능
  • 각 항목별 노출 유무 ON/OFF 제어
  • 운영팀이 별도 개발 없이 다양한 형태의 배너 구성 가능
Filter

Feature 02

쇼핑 큐레이션
필터 UI 커스터마이징

카페24 기본 쇼핑 큐레이션의 제한적인 필터 기능을 스크립트로 확장하여, 메탈 컬러·컬렉션·테마 등 구성별 다중 필터를 자유롭게 적용할 수 있도록 구현했습니다.

  • 카페24 쇼핑 큐레이션 기능 스크립트 기반 커스터마이징
  • 메탈 컬러 / 컬렉션 / 테마 등 구성별 필터 UI 구현
  • 필터 조합 시 해당 상품만 동적 노출
API

Feature 03

컬러칩 클릭 시
연관 상품 정보 API 연동

상품 목록에서 동일 제품군의 컬러 베리에이션을 컬러칩으로 표현하고, 클릭 시 API를 통해 해당 컬러 상품의 썸네일·가격·링크를 실시간으로 교체하는 기능을 구현했습니다.

  • 상품 목록 내 동일 제품군 컬러칩 UI 구현
  • 컬러칩 클릭 → API 호출 → 썸네일·가격·링크 동적 변경
  • 페이지 이동 없이 상품 컬러 프리뷰 제공
Maps

Feature 04

Google Maps 및 API 연동
매장 찾기 기능 구현

매장 관련 API와 Google Maps를 연동하여 사용자가 가까운 판도라 매장을 지도에서 탐색할 수 있는 매장 찾기 기능을 구현했습니다.

  • 매장 API 연동으로 실시간 매장 데이터 표시
  • Google Maps 기반 지도 마커 및 매장 위치 시각화
  • 키워드 검색 및 지역 기반 매장 필터링
  • 마커 클릭 시 매장 상세 정보 패널 노출
UI

Feature 05

프론트 API 기반
상품 분류 카테고리 UI

카페24 기본 모듈 대신 프론트 API를 직접 활용하여 브랜드 디자인에 맞는 커스텀 카테고리 UI를 구현하고, 선택한 카테고리에 따라 상품 목록을 동적으로 렌더링했습니다.

  • Cafe24 프론트 API 활용하여 별도 카테고리 UI 구현
  • 카테고리 탭 선택 시 상품 목록 동적 렌더링
  • 기본 모듈 제약 없이 디자인 자유도 확보

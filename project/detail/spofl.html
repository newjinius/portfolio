Feature 01 — 브랜드관 개편

브랜드별 일관된
사용자 경험 제공

브랜드 콘텐츠를 스냅·매거진·스토어·A/S·스토리 탭으로 구조화하고, API 연동과 파라미터 기반 콘텐츠 연동으로 브랜드마다 일관된 쇼핑 경험을 제공하도록 개편했습니다.

  • 브랜드 콘텐츠 5종(스냅·매거진·스토어·A/S·스토리) 탭 UI 구성
  • API 연동을 통한 콘텐츠 유형별 동적 노출
  • 카페24 상품 분류 상단 이미지 활용을 위한 별도 HTML 구성
  • 파라미터(cate_no) 기준 배너·콘텐츠 연동 구조 설계
Maps 2025.07, 10

Feature 02 — 스트링 서비스 고도화

매장 기반
라켓 스트링 교체 서비스

API와 카카오맵을 연동하여 사용자가 가까운 매장을 찾고 스트링 교체를 신청할 수 있는 end-to-end 서비스 플로우를 구축했습니다.

  • API 연동으로 매장 리스트 실시간 호출
  • 카카오맵 연동 매장 찾기 기능 구현
  • 매장 기준 스트링 교체 신청 폼 UI 구현
  • 마이페이지 내 신청 내역 및 369 이벤트 참여 영역 구현
Shortform 2025.07 – 08

Feature 03 — 스포쇼 고도화

숏폼 영상 콘텐츠
커머스 기능 고도화

스포플의 숏폼 영상 커머스 서비스 스포쇼를 고도화했습니다. PC·모바일 환경별 자동재생 UX, 스크롤 기반 게시글 전환, 연관 상품 API 연동까지 몰입감 있는 숏폼 커머스 경험을 구현했습니다.

  • PC: 썸네일 hover 시 / MO: 스크롤 기준 최상단 좌측 영상 자동재생
  • 숏폼 상세 진입 시 스크롤 기반 게시글 전환 UX 구현
  • 연관 상품 및 연관 큐레이터 정보 API 연동 및 UI 구성

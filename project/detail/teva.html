글로벌 아웃도어 샌들 브랜드 테바(Teva) 한국 공식몰에서 상품 목록 페이지 UX 개선을 담당했습니다.
기존에는 컬러 변형마다 별도 상품으로 나열되던 방식을 개선하여, 하나의 상품 카드에서 컬러칩 클릭만으로 썸네일과 링크가 전환되는 인라인 컬러 탐색 UX를 구현했습니다.

Before

허리케인 XLT3 (BKO), 허리케인 XLT3 (BLK), 허리케인 XLT3 (TAN)… 컬러별 개별 상품 카드 나열 → 목록 페이지가 중복 상품으로 가득 참

After

허리케인 XLT3 카드 1개 + 하단 컬러칩 → 칩 클릭 시 썸네일·링크 즉시 전환. 목록 페이지 정리 + 컬러 탐색 편의 동시 확보

Color Chip

Feature 01 — UX

상품 카드 내
인라인 컬러 탐색 UI 구현

상품 목록 카드 하단에 연관 컬러 모델의 컬러칩을 노출하고, 칩 클릭 시 썸네일 이미지와 상품 링크가 즉시 전환되는 인라인 컬러 탐색 UX를 구현했습니다. 상세 페이지 이동 없이 목록에서 원하는 컬러를 바로 선택하여 구매로 진입할 수 있습니다.

  • 상품 카드 하단 컬러칩 영역 HTML/CSS 설계 및 구현
  • 칩 클릭 시 카드 썸네일 이미지 즉시 교체 (DOM 조작, 페이지 이동 없음)
  • 칩 클릭 시 상품 카드 링크 대상 URL 동적 변경 → 선택 컬러 상품 상세로 직행
  • 활성 칩 시각적 표시(border·shadow) 처리로 현재 선택 컬러 명확히 인지

Feature 02 — API

Cafe24 관련상품 기능
API 연동 및 데이터 처리

Cafe24 관리자에서 설정된 관련상품(연관 컬러 모델) 정보를 프론트 API로 호출하여 컬러칩에 필요한 데이터(썸네일 URL·상품 번호·컬러명)를 동적으로 바인딩했습니다. 운영팀이 관련상품만 등록하면 자동으로 컬러칩이 생성되는 구조입니다.

  • Cafe24 관련상품 API 엔드포인트 분석 및 프론트 호출 구현
  • API 응답에서 연관 상품별 썸네일·상품번호·컬러 정보 파싱
  • 파싱된 데이터로 컬러칩 동적 생성 — 관련상품 추가 시 칩 자동 반영
  • 상품별 API 호출을 목록 렌더링 시점에 배치 처리하여 성능 최적화
운영 자동화: 관리자에서 컬러 모델을 "관련상품"으로 등록하기만 하면 프론트에서 API로 자동 조회 → 컬러칩 자동 생성. 개발 수정 없이 운영팀이 컬러 추가·삭제 가능.

Responsive Design

손가락 하나로
원하는 컬러 바로 선택

모바일에서 컬러칩은 터치 최적화된 크기로 제공됩니다. 손가락으로 칩을 탭하면 썸네일이 즉시 전환되어 상세 페이지를 여러 번 드나들 필요 없이 목록에서 원하는 컬러를 바로 확인하고 선택할 수 있습니다.

👆
터치 최적화 컬러칩 모바일 터치 타겟 기준에 맞는 칩 크기로 오탭 없이 정확한 컬러 선택
🖼️
즉각 썸네일 전환 API 응답 이미지 URL로 즉시 교체 — 이미지 깜빡임 없는 부드러운 전환
📋
목록 밀도 개선 컬러별 개별 카드 나열 제거 → 상품 수 감소, 스크롤 탐색 효율 향상

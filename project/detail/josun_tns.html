조선호텔&리조트가 운영하는 프리미엄 식품 브랜드 온라인몰의 브랜드 사이트 리뉴얼 프로젝트입니다.
기존 외부 API 기반 구조를 Cafe24 네이티브 모듈로 전환하여 관리 채널을 일원화하고, VIP·임직원·일반 회원별 UI 분기 처리와 기획전 페이지 커스터마이징을 통해 프리미엄 쇼핑 경험을 구현했습니다.

— Key Features

담당 기능 구현한 주요 기능들

Core

Feature 01

기존 API 기반 영역을
Cafe24 모듈로 전환

Cafe24 기능에 대한 깊은 이해를 바탕으로 기존 외부 API 기반 기능을 Cafe24 기본 모듈과 프론트 API로 이전하여 관리 채널을 일원화하고 운영 효율을 높였습니다.

  • 외부 API 의존 구조를 Cafe24 네이티브 모듈로 전환
  • 프론트 API 활용으로 상품·회원 데이터 연동 최적화
  • 관리 채널 일원화로 운영 및 유지보수 효율 개선
  • Cafe24 모듈 기능의 한계를 커스터마이징으로 확장
CMS

Feature 02

배너매니저 앱 활용
유지보수 효율 개선

배너매니저 앱을 도입하여 다양한 콘텐츠 유형에 유연하게 대응할 수 있는 배너 관리 시스템을 구축하고, 비개발자도 손쉽게 콘텐츠를 운영할 수 있는 환경을 마련했습니다.

  • 배너매니저 앱 기반 콘텐츠 관리 시스템 구축
  • 이미지·텍스트·동영상 등 다양한 콘텐츠 타입 대응
  • 운영팀 직접 관리 가능한 구조로 유지보수 비용 절감
Auth

Feature 03

회원 등급별
구매 권한 분기 처리

VIP 회원·일반 회원·임직원 회원 각 등급에 따라 노출 콘텐츠와 구매 권한이 달라지는 UI 분기 처리를 구현하여 차별화된 프리미엄 쇼핑 경험을 제공합니다.

  • VIP / 일반 / 임직원 3단계 회원 등급별 UI 분기
  • 등급별 접근 가능한 상품 및 혜택 노출 제어
  • 비로그인 / 등급 미달 시 안내 처리 및 리다이렉션
VIP

Feature 04

VIP 전용관 및
기획전 페이지 커스터마이징

상품 전용 페이지가 아닌 일반 콘텐츠 페이지에서도 Cafe24 상품 모듈을 활용할 수 있도록 커스터마이징하여 VIP 전용관과 시즌 기획전 페이지를 구성했습니다.

  • 비상품 페이지에 Cafe24 상품 모듈 삽입 커스터마이징
  • VIP 회원 전용 혜택·상품 노출 전용관 구현
  • 시즌·테마별 기획전 페이지 레이아웃 제작
  • 등급별 진입 시 맞춤 콘텐츠 자동 노출
UI

Feature 05

메인 배너 스와이퍼
동적 텍스트 컬러 제어

메인 배너 슬라이드의 배경 컬러 값을 읽어 밝기(luminance)에 따라 텍스트와 UI 요소 컬러를 자동으로 전환하는 스크립트를 구현하여 어떤 배경에도 가독성을 확보했습니다.

  • 배너 배경 컬러 luminance 분석 후 텍스트 컬러 자동 전환
  • 밝은 배경 → 어두운 텍스트 / 어두운 배경 → 밝은 텍스트
  • Swiper 슬라이드 전환 시 실시간 컬러 업데이트
  • 운영팀이 배경 컬러만 지정하면 자동 대응되는 접근성 보장 구조
